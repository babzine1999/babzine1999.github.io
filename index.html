A 3-page Power BI dashboard analyzing AdventureWorks Cycles' sales performance, built on a full star-schema data model (Sales, Returns, Products, Customers, Territories). Tools: Power BI, DAX, SQL Server  |  Analysis: Root-Cause Analysis, Data Validation
